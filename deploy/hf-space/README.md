# Vouch — memory you can trust

An always-on personal AI assistant that knows where every memory came from, so a web page, an email or a
malicious skill can never quietly rewrite what it believes or does. Runs on NVIDIA Nemotron models via
Nebius Token Factory, with Tavily as its only window to the web.

Open the **Attack Lab** and press Run on A1 to watch a naive memory agent get poisoned while Vouch catches
the same attack. Free CPU Spaces sleep when idle: the first request can take ~30 s to wake the app.

Source, setup and evals: see `GITHUB_README.md` in this Space or the GitHub repository.
